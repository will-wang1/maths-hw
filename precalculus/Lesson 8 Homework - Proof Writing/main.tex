\section{}
We have 
\[\tan(\frac{\pi}{12})\tan(\frac{2\pi}{12})\tan(\frac{3\pi}{12})\tan(\frac{4\pi}{12})\tan(\frac{5\pi}{12})\]
We can use the definition of $\tan$ to turn each part into a form of $\frac{\sin x}{\cos x}$
\[\frac{(\sin(\frac{\pi}{12}))(\sin(\frac{2\pi}{12}))(\sin(\frac{3\pi}{12}))\sin((\frac{4\pi}{12}))(\sin(\frac{5\pi}{12}))}{(\cos(\frac{\pi}{12}))(\cos(\frac{2\pi}{12}))(\cos(\frac{3\pi}{12}))(\cos(\frac{4\pi}{12}))(\cos(\frac{5\pi}{12}))}\]
Then we can use the complementary angle identity to change the $\cos$ to $\sin$. 
\[\frac{(\sin(\frac{\pi}{12}))(\sin(\frac{2\pi}{12}))(\sin(\frac{3\pi}{12}))\sin((\frac{4\pi}{12}))(\sin(\frac{5\pi}{12}))}{(\sin(\frac{5\pi}{12}))(\sin(\frac{4\pi}{12}))(\sin(\frac{3\pi}{12}))(\sin(\frac{2\pi}{12}))(\sin(\frac{\pi}{12}))}\]
Notice that the bottom just cancels out, hence
\[=1\]

\[\text{LHS} = \frac{\tan x}{1 - \cot x} + \frac{\cot x}{1 - \tan x}\]
\[= \frac{\frac{\sin x}{\cos x}}{1 - \frac{\cos x}{\sin x}} + \frac{\frac{\cos x}{\sin x}}{1 - \frac{\sin x}{\cos x}} \]
\[= \frac{\sin x / \cos x}{(\sin x - \cos x)/\sin x} + \frac{\cos x / \sin x}{(\cos x - \sin x)/\cos x} \]
\[= \frac{\sin^2 x}{\cos x(\sin x - \cos x)} - \frac{\cos^2 x}{\sin x(\sin x - \cos x)} \]
\[= \frac{\sin^3 x - \cos^3 x}{\sin x \cos x (\sin x - \cos x)} \]
\[= \frac{(\sin x - \cos x)(\sin^2 x + \sin x \cos x + \cos^2 x)}{\sin x \cos x (\sin x - \cos x)} \]
\[= \frac{\sin^2 x + \sin x \cos x + \cos^2 x}{\sin x \cos x} \]
\[= \frac{1 + \sin x \cos x}{\sin x \cos x} \]
\[= \frac{1}{\sin x \cos x} + 1 \]
\[= \sec x \csc x + 1 = \text{RHS}\]
