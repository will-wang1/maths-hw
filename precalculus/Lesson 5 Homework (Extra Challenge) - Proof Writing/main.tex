We want $\sin 3\theta < 0.5 \implies \sin 3\theta < \sin \frac{\pi}{6}$. If consider the unit circle, then we can just add on periods of $2\pi$ later since the sine function is periodic. 

\[\sin x = \tfrac{1}{2} \implies x = \frac{\pi}{6} + 2k\pi \quad \text{or} \quad x = \frac{5\pi}{6} + 2k\pi, \quad k \in \mathbb{Z}\]
Hence
\[\sin x < \tfrac{1}{2} \text{ for } x \in \left( \frac{5\pi}{6} + 2k\pi, \, 2\pi + \frac{\pi}{6} + 2k\pi \right)\]
Then we can just substitute $x = 3\theta$
\[3\theta \in \left( \frac{5\pi}{6} + 2k\pi, \, 2\pi + \frac{\pi}{6} + 2k\pi \right), \quad k \in \mathbb{Z}.\]
Therefore 
\[ \theta \in \left( \frac{5\pi}{18} + \frac{2k\pi}{3}, \, \frac{13\pi}{18} + \frac{2k\pi}{3} \right), \quad k \in \mathbb{Z}\]
