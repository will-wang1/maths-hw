Let 
\[g(x) = x+1\]
and 
\[f(x) = \begin{cases}
    1 & \text{if } x = 1
    \\ 0 & \text{if } x \neq 1
\end{cases}\]
Both of these functions are continuous at \(x= 0\) since \(f(x)\) is only discontinuous at \(x=1\). Then 
\[(f\circ g)(x) = f(x+1) = \begin{cases}
    1 & \text{if } x = 0
    \\ 0 & \text{if } x \neq 0
\end{cases}\]
This is discontinuous at \(x = 0\) since 
\[(f\circ g)(0) = 1\]
which is not equal to the right and left side limits 
\[\lim_{x\to 0^-} (f\circ g)(x) = \lim_{x\to 0^+} (f\circ g)(x) = 0\]
which doesn't satisfy the definition of the limit. This doesn't contradict Theorem 8 since it only holds when \(f\) is continuous at \(g(x)\) which is not true since 
\[g(x) \in (-\infty, \infty)\]
while \(f\) is not continuous for all real numbers.
